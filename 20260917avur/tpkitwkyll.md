# 黄体功能不全与卵巢早衰有关吗？

> 更新时间：2026-09-17 (UTC+8)

**点击蓝字 关注我们**

黄体功能不全与卵巢早衰有关系，但不是一回事。黄体功能不全是排卵后黄体不行，孕酮低、内膜长不好 → 容易着床失败、早期流产、月经偏短。卵巢早衰是卵巢里卵泡储备太少、功能提前衰退 → 不怎么排卵、月经稀发/闭经、FSH高、AMH低。

卵巢早衰常会伴随黄体功能不全。卵巢储备差 → 卵泡质量差 → 排卵后形成的黄体功能弱 → 孕酮不足。所以很多卵巢早衰/储备差的人，同时有黄体功能不全。

但黄体功能不全不等于卵巢早衰，很多人只是单纯黄体弱，AMH、窦卵泡、卵巢储备完全正常。这种只是排卵后孕酮不够，不是卵巢早衰。

当月经周期＜21天、高温期＜10–12天、排卵后孕酮偏低，怀疑黄体功能不全。而年龄＜40岁、月经紊乱/闭经、AMH极低、FSH升高、窦卵泡少，怀疑卵巢早衰。
